# B585 DP2 二阶倒立摆 LQR 模型（复现在案）

模型与增益**完全复现**厂商 MATLAB 脚本 `inverted_pendulum_on_self_balancing_robot.m`，复现误差 max|ΔK| = 4.35e-05（固件里保留 4 位小数所致）。

## 1. 状态与输入

```
x = [θL, θR, θ1, θ2, θL̇, θṘ, θ1̇, θ2̇]^T      u = [T_L, T_R]^T
```

- θL, θR：左右轮转角（rad）
- θ1：车身倾角（rad）；θ2：摆杆绝对角（rad）
- 后四维为对应角速度

## 9. 复现方式

```bash
.venv/bin/python firmware/lqr_model/lqr_design.py
```

脚本按 `Q diag × 系数` 可生成任意调参版本（改 `solve(qw)` 的 `qw` 即可）。
