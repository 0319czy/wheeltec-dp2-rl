# DP2 上位机桥协议 v1

> 适用范围：笔记本（上位机）↔ WHEELTEC B585 DP2 平衡车（STM32F103，下位机）。
> 当前阶段**只在 mock 跑通**：`deploy/bridge.py --mock` 不打开串口、不连真车。
> 参考实现：`wheeltec_rl/tools/bt_remote/server.py`（只读）、固件 `MiniBalance/show.c`、`HAREWARE/usart3.c`。
> 固件改动方案见 [`firmware-notes.md`](firmware-notes.md)。

## 1. 链路与端口

| 链路 | MCU 外设 | 参数 | 说明 |
|---|---|---|---|
| 蓝牙模块 | USART3 | **9600 8N1** | 厂商 APP 走的通道，单字符遥控 |
| USB Type-C（CH9102） | USART1 | **115200 8N1** | 2026-11 补丁加入，与蓝牙并行，单字符遥控 |
| N10 雷达 | UART5 | 230400 | 本项目不用 |

- 两个通道都进固件 `Remote_Command()`，语义完全一致。
- 上位机默认发 **10 Hz**；厂商遥控是「按住重复发」，参考 server.py 用 20 Hz。
- 固件有 **300 ms 无指令看门狗**（`control.c` 的 `Normal()` 中 `Remote_Last_Cmd_Tick`），停发 0.3 s 自动清零方向。

```
上位机                                          DP2 平衡车
camera 128x128 ─┐
语音/文本指令 ──┴► VLA 10 Hz ──(v, ω) 帧──► USART3/USART1 ──► Normal() ──► LQR/PI 100 Hz ──► PWM
                          ▲                                        │
                          └────────── {A/B/D/E...}$ 遥测 ◄─────────┘
```

## 2. 下行 A：现有单字符遥控（保持兼容，不改固件）

| 字符 | 十六进制 | 行为 | 固件路径 |
|---|---|---|---|
| `A` | 0x41 | 前进 | `Flag_front=1, Flag_back=0` |
| `E` | 0x45 | 后退 | `Flag_back=1, Flag_front=0` |
| `G` | 0x47 | 左转 | `Flag_Left=1, Flag_Right=0` |
| `C` | 0x43 | 右转 | `Flag_Right=1, Flag_Left=0` |
| `Z` | 0x5A | 停车 | 四个 Flag 全清 |
| `Y` / `X` | 0x59 / 0x58 | 加速 / 减速档 | `Flag_velocity=2/1` |
| `b` | 0x62 | 雷达避障开关 | `Avoid_Flag` 取反 |
| `0x00`–`0x08` | 数字 | APP 的方向字节 | 与 A/E/G/C/Z 等价（见 usart3.c） |

- 组合运动：服务端可以一次发多个字符（如 `AG` = 前进+左转），固件里前进/后退与左/右转是独立 Flag，可叠加。
- 只发 `G`/`C` 时 `v=0`（原地旋），但固件的 `turn_speed` 步长固定。
- **局限**：单字符无法表达任意 (v, ω)，只有固定步长（见 §5 换算），只能做离散档位。

bridge 的 `--proto legacy` 就是把 VLA 的 (v, ω) 量化成 `A/E/G/C/Z(+G/C)` 字符流：

```
v=+0.25 ω=0      → "A"
v=-0.20 ω=0      → "E"
v=+0.15 ω=+0.80  → "AG"
v=0     ω=-1.00  → "C"
v≈0     ω≈0      → "Z"
```

## 3. 下行 B：连续 (v, ω) 速度帧（新增，需固件补丁）

### 3.1 帧格式

```
#V<v_mm_s>,<w_mrad_s>;
```

- ASCII，以 `#` 开头、`;` 结尾，无空格（复用固件现有 `#...;` 参数通道）。
- `v_mm_s`：有符号十进制整数，前进为正，单位 **mm/s**，范围 `[-350, 350]`（spec §2）。
- `w_mrad_s`：有符号十进制整数，左转/逆时针为正，单位 **mrad/s**，范围 `[-1000, 1000]`。
- 长度 ≤ 12 字节，10 Hz 发送（最少 3.4 Hz 才不会触发 300 ms 看门狗）。

示例：

| 指令 | (v, ω) | 帧 |
|---|---|---|
| 保持站立 | 0, 0 | `#V0,0;` |
| 向前走 | 0.25, 0 | `#V250,0;` |
| 向后退 | -0.20, 0 | `#V-200,0;` |
| 向左转 | 0.15, +0.8 | `#V150,800;` |
| 向右转 | 0.15, -0.8 | `#V150,-800;` |
| 原地左旋 | 0, +1.0 | `#V0,1000;` |
| 原地右旋 | 0, -1.0 | `#V0,-1000;` |

### 3.2 兼容替代：复用 `#vc=` / `#wc=`

如果不想动 `usart3.c` 的解析器，也可以发两条现有语义的参数帧（10 Hz 共 20 帧/s，9600 波特率仍够）：

```
#vc=0.250;#wc=0.800;
```

> 注意：`DP2_RL_FIRST_ORDER/HAREWARE/usart3.c` 里虽然已经能解析 `#vc=`/`#wc=`（写入 `RL_Vcmd/RL_Wcmd`），
> 但当前没有任何控制代码读取这两个变量（**死代码**，见 firmware-notes），所以仍需改 `control.c`。

### 3.3 优先级与互锁

1. 最近 300 ms 内收到过合法 `#V...;`（或 `#vc/#wc`）→ **VLA 模式**，`Normal()` 忽略单字符 Flag，按 (v, ω) 积分目标轮角。
2. 超过 300 ms 没收到 VLA 帧 → 自动退出 VLA 模式、零速，回到单字符遥控。
3. `Z` 单字符始终可立即停车（最高优先级）。
4. 固件 `Turn_Off()` 的 40° 倾角 / 11.1 V 欠压保护不变，VLA 不能绕过。

## 4. 上行：遥测帧 `{...}$`

固件从 `MiniBalance/show.c` 的 `APP_Show()` 发送，帧以 `$` 结尾，`{}` 内冒号分隔。
上位机按 `$` 切帧、严格过滤非数字/NaN，缓冲上限 4 KB（与 server.py 的容错策略一致）。

| 帧 | 字段 | 单位/含义 |
|---|---|---|
| `{A...}` | 左轮速 : 右轮速 : 电量 : 平衡倾角 | 轮速 = 实测 mm/s × 1.1 后**取绝对值**；电量 0–100 %；倾角 ° |
| `{B...}` | Pitch : Roll : Yaw | 姿态角，°（波形页） |
| `{C...}` | 参数回显 | `#...;` 设置后的字符串回显 |
| `{D...}` | Flag_Stop : Voltage : PWM_L : PWM_R : APP_ON | 电压单位 0.01 V；PWM 有符号 |
| `{E...}` | 12 个整数 | θ1/θ2（0.01°）、左右轮速（0.001 rad/s）、陀螺、线速度 mm/s、轮角、位移 mm、电压、ADC |

**重要**：A 帧的左右轮速在固件里取了绝对值（`if<0` 时取反），**不能区分正反转**；
要判断方向请用 `{D...}` 的 PWM 符号或 `{E...}` 的线速度。bridge 的 mock 遥测为了直观保留了符号，解析真实帧时需注意这点。

典型原始帧（mock 日志同格式）：

```
{A250:250:81:1}$     左/右轮 250 mm/s、电量 81%、倾角 1°
{D0:1210:350:350:1}$ Flag_Stop=0、12.10 V、PWM 350、APP_ON=1
```

## 5. 与固件常量/量纲的对应

`control.c` 每 10 ms 调一次 `Normal()`，`control.h` 里：

```c
#define movement_speed 0.05   // 前进/后退：目标轮角增量 rad / 10 ms
#define turn_speed     0.02   // 转向：左右目标轮角增量 rad / 10 ms
```

按轮半径 `r=0.0335 m`、半轮距 `b=0.095 m` 换算（来自 `assets/lowlevel/dp2_nopole3d.xml`）：

- 前进：`v = 0.05 / 0.01 * 0.0335 ≈ 0.1675 m/s`
- 原地转向：`ω = 0.02 / 0.01 * 0.0335 / 0.095 ≈ 0.705 rad/s`

所以现有单字符遥控大约是「v=0.17、ω=0.7」的固定档位；VLA 需要 0–0.35 m/s、0–1.0 rad/s 的连续值，
必须用 §3 的帧 + 固件补丁。反向换算（bridge/固件共同使用）：

```
Δθ_L = (v - ω·b) · dt / r
Δθ_R = (v + ω·b) · dt / r      # dt = 0.01 s
```

## 6. 安全设计（上层）

- bridge 退出 / Ctrl-C → 最后一定发 `#V0,0;`（legacy 模式发 `Z`）。
- 单帧策略耗时 > `--watchdog-ms`（默认 300 ms）→ 本帧改发零速。
- 指令未识别（normalize 返回 id=None）→ 保持站立，绝不猜一个运动指令。
- 真串口必须 `--serial` + `--allow-real` + 环境变量 `DP2_ALLOW_REAL=1` 三者同时满足，否则拒绝打开。
- 实机调试顺序：架空轮子 → 只发 `#V0,0;` 看 `{D}` → v=±0.05 低速 → 手持保护 → 再放开。
