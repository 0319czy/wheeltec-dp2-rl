# 底层策略选型记录（2026-11-22）

VLA 只输出 10 Hz 的 (v, ω)，底层需要一个 100 Hz 的平衡/速度环把速度指令执行掉。本文件记录备选与最终选择。

## 候选与判据

从 `wheeltec_rl/runs/mujoco_cmd3d*` 里 23 个 (model, VecNormalize) 组合，在固定 5 s 回合、单 seed 下测 7 条指令：

| 指令 | 成功判据 |
|---|---|
| 站立 (0, 0) | 位移 < 0.10 m 且 Δyaw < 0.20 rad |
| 前进 (0.25, 0) | 前向位移 ∈ [0.5, 1.9] m |
| 后退 (−0.20, 0) | 后退位移 ∈ [0.35, 1.5] m |
| 左转 (0.15, +0.8) | Δyaw ∈ [1.0, 3.5] rad 且前向 > 0.15 m |
| 右转 (0.15, −0.8) | Δyaw ∈ [−3.5, −1.0] rad 且前向 > 0.15 m |
| 左旋 (0, +1.0) | Δyaw ∈ [1.5, 5.0] rad 且位移 < 0.40 m |
| 右旋 (0, −1.0) | Δyaw ∈ [−5.0, −1.5] rad 且位移 < 0.40 m |

复跑：`.venv/bin/python scripts/ll_sweep.py`（CPU，约 2 分钟）。

## 结论

`assets/lowlevel/balance_model.zip` + `assets/lowlevel/vecnormalize.pkl` 固定为
`wheeltec_rl/runs/mujoco_cmd3d/fix_mixed-v0.3-w1.2(.zip / _vec.pkl)` 这一对（md5 `6593f2f5…`）。

## 两个必踩的坑

1. **必须用 VecNormalize.normalize_obs**（`training=False`）喂策略，否则输出恒 0，车不动。
2. **Δyaw 必须逐帧 unwrap 累加**：累计 ~3.1 rad 时首末差会回绕成 −3.0，判据误判。`sim/env_vla.py` 用累加值。
