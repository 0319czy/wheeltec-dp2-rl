# DP2 调试日志

本页记录已经执行的定位、调整和复测。涉及的通过率均来自 MuJoCo 仿真。完整课程和参数见 [训练日志](TRAINING_LOG.md)。

## 2026-11-20 · 一阶小车保持平衡，但会漂出范围

**现象。** 直接 PWM 的旧策略加上台架限幅后，无推扰只有 4/50 局达到 5 秒。部分回合尚未倒下，就因位移超过 0.20 m 提前结束。

**定位。** 按位移和倾角分别统计结束原因。用编码器轮速与车身俯仰角速度估算车速和里程，并把估算量送入策略。以此检查使用固件观测公式后，策略在闭环中的表现。

**处理与复测。** 保留 ±2500 PWM 和位移保护，重训时增加位置与速度代价。第 3 个检查点在无推扰、有推扰两组各完成 50/50 局，估算最大位移分别为 59 mm 和 69 mm。第 5 个检查点位移较小，但要求更大的 PWM 峰值，台架候选因此选用第 3 个检查点。[一阶抗扰评估](../results/first-order/robust/evaluation.json)

## 2026-11-20 · 一阶 PWM 幅值下降，跳变却增大

**现象。** 权重平均方案把强扰动下的位移 P95 从 137 mm 降到 95 mm，但 PWM 跳变 RMS 从 80 升到了 94。PWM 幅值和相邻步变化是两个不同的指标。

**定位。** 同一批种子下同时记录完成局数、位移 P95、PWM 幅值 RMS 和相邻步差分 RMS。第一轮专门压跳变的 PPO 在 24 秒强扰动测试中把跳变 RMS 从 94.6 降到 90.2，位移 P95 却从 144 增到了 152 mm。再提高位移代价也没能恢复原水平。

**处理与复测。** 采集 50,400 个教师状态训练平滑候选。平稳状态使用较平滑的目标，高角速度时保留快速纠偏目标。独立 60 秒强扰动组中，旧版和新版均完成 20/20 局。新版将跳变 RMS 从 97.2 降到 84.8，位移 P95 从 133 降到 132 mm，PWM 幅值 RMS 从 286 升到 291。[平滑复测与训练配置](../results/first-order/slew/evaluation.json)

以下命令可复跑这组测试。

```bash
python mujoco/train_direct_pwm_robust.py \
  models/first-order/policy.zip models/first-order/vecnormalize.pkl \
  --episodes 20 --seconds 60 --seed 99735 --scenario stress
```

## 2026-11-20 · 二阶加入扰动后，车身先越过倾角保护

**现象。** 小倾角训练组完成 12/12 个 8 秒回合。直接增大初始偏差，并混合动作延迟和推扰后，12 秒测试降到 0/16。

**定位。** 保留同一早期策略，每种条件分别做 12 个 8 秒回合。

| 条件 | 完成 | 平均时长 | 车身倾角超限 |
| --- | ---: | ---: | ---: |
| 只加推扰 | 1/12 | 3.83 s | 11 局 |
| 只扩大初始角 | 8/12 | 5.40 s | 4 局 |
| 只加动作延迟 | 10/12 | 6.72 s | 2 局 |
| 动作延迟和推扰 | 1/12 | 2.62 s | 11 局 |

**处理与复测。** 在部分训练环境里把首个小推扰提前到回合开始后 0.25–0.70 秒，增加恢复样本，并保留无推扰分支。之后用仿真回合回报搜索输出层参数。最终候选在独立 30 秒轻推扰组完成 32/32，60 秒无推扰组完成 20/20。较难的 20 秒组仍只有 9/24，另外 15 局都因车身倾角超限而结束。[单因素与最终复测](../results/second-order/balance/evaluation.json)

## 实机待测

一阶候选的 2,000 组主机推理比对中，C 与 Python 的最大动作差为 2.980e-7。该测试验证数值推理。板上控制周期、车轮与 IMU 的方向和比例仍需测量。二阶还需核对摆杆零点，并确认车身角与铰链相对角的合成方向。仓库暂无两套策略的实机闭环日志。
