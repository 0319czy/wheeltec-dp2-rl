# 实机记录：部署、故障、定位与结论

本页只写**已经在实机发生过并留下数据**的事；没有实机记录的结论不会写在这里。
原始数据：`docs/real-trace-100hz.csv`（128 帧，100 Hz 控制缓存）。

## 1. 部署链路

| 环节 | 实现 |
| --- | --- |
| 姿态 | MPU6050 + DMP，俯仰角与角速度在 5 ms 中断内更新 |
| 轮速/里程 | 编码器差分计数 → rad/s；里程按 `0.0335·(wl+wr)/2` 积分 |
| 策略输入 | 6 维观测 `[pitch*4, rate*0.5, wl/20, wr/20, distance*2, velocity*2]` |
| 策略输出 | 左右轮 PWM，直接下发（限幅 ±2500） |
| 保护 | 俯仰 45° 停机、300 ms 心跳失联、位移 0.20 m、轮速 16 rad/s、电压门限 |
| 解锁 | 一次性显式解锁；保护触发后必须重新解锁 |

## 3. 两次失败

**第一次（融合策略）**：起始倾角约 +20.17° 解锁后，D 帧锁存范围位=2、行程 19 mm、
左右轮速 16.160 / 15.175 rad/s —— 触发**左轮速保护**停机。该策略**未通过验收**。

**第二次（漂移补偿融合候选）**：仿真里 ±2° 零位偏差保持从 0/12 提升到 12/12，
但大角度回正退化（±7.8° 从 16/16 降到 10/16）；实机再次触发轮速保护，未通过。

## 4. 已排除与仍未定位

- **已排除**：「10 Hz 振荡 = 单纯控制时延」。用动作时延 0/10/20 ms + 观测时延 0/10 ms
  做课程训练后，独立评估反而更差（大角度回正 6/16 → 0/16），说明该假设不成立。
- **仍未定位**：约 200 mm 的单向漂移来源。仿真同一策略 12 局 × 15 s 行程 P95 仅 1.6–1.7 cm，
  **仿真复现不出实机故障**，因此不能靠调仿真参数解决，需要继续取实机数据。
- **物理边界**：单轮力矩上限 0.0402 N·m、车身 0.9 kg、重心高 0.09 m →
  稳态可支撑最大倾角 ≈ 2.9°，超过即无法靠力矩硬撑回正。

## 5. 下次实机测试的顺序（记录待办）

1. 先测 `#kx=0` 基线（当前默认），再测 `#kx=4140` 对照，用实机数据决定取舍；
2. 导出 100 Hz 缓存，对比 `pitch` 与 `wheel` 相位，判断振荡是传感器时延还是机械/打滑；
3. 若确认为打滑或机械偏心，先做机械检查（轮径一致性、轮毂偏心、地面清洁），再谈策略。
