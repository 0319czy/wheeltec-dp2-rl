# DP2 纯 RL 训练日志

记录覆盖 2026-11-20 的一阶台架候选、两轮一阶续训和二阶带杆训练。运行目录中的配置、选型评估和复测输出集中保存在 [results/](../results/)。历史配置引用的工作目录已改为相对路径。选型过程中产生的中间权重由本地训练目录保存，仓库提供最终候选及主要对照权重。

## 实验边界和指标

- 一阶为无杆两轮平衡，二阶使用带被动摆杆的两轮模型。两种环境均在 MuJoCo 平面内推进，100 Hz 控制。策略直接生成左右轮 PWM 指令。
- 完成局数指完整跑到回合上限的局数。平均时长百分比是另一种统计量，两者分别报告。
- 位移峰值 P95 是先对每局取最大绝对位移，再在全组回合间算第 95 百分位。PWM 跳变 RMS 用相邻控制步的指令差计算。PWM 幅值和跳变都以计数为单位。
- 测试中的推扰强度、摩擦与执行延迟属于仿真设置。仿真完成率无法直接外推到真车。当前两种策略都只验收原地站立。
- 复现默认用 Python 3.10、MuJoCo 3.17.0、CPU PyTorch 2.9.1、SB3 2.9.2、Gymnasium 1.4.0、NumPy 2.2.6。

## 一阶基线与台架约束

1. 早期 `finetuned` 运动模型的动作是轮加速度，依赖下游轮速 PI。纯 PWM 路线改用无杆、直接力矩的模型。首轮模型加上台架限幅和位移保护后，无推扰只完成 4/50 个 5 秒回合。
2. 失败多集中在持续漂移，而非立即翻倒。训练环境保留 ±2500 PWM、0.20 m 位移、0.09 rad 俯仰及 16 rad/s 轮速限制，重训时增加位置与速度代价。
3. 从随机初始化训练的新策略中，第 3 个检查点在独立评估里，无推扰及 `push=0.2` 两组均完成 50/50 个 5 秒回合。按固件观测公式估算的最大位移分别为 0.059 m 和 0.069 m。第 5 个检查点位移更小，所需 PWM 峰值更大，因此台架基线采用第 3 个检查点。
4. 台架固件原型采用只读遥测与限时站立两个构建。曾用 2,000 组输入验证 C/Python 推理一致性，并对上电关断、失联、运动边界和故障路径做主机模拟。真实传感器符号、量纲和板上周期需要台架测量。没有 DP2 真车闭环验收记录。

## 一阶抗扰续训

将编码器量化、轮速里程估算、IMU 零偏、左右电机增益差、PWM 死区和重复推扰加入前向仿真。这里的传感器与电机差异是测试假设。观察统计保持冻结。动作接口是 6 维观测到 2 维 PWM。归一化参数必须和模型一起使用。

| 分支 | 步数与选型经过 |
| --- | --- |
| r1 | 32,768 步。标准推扰组位移 P95 由 96 mm 增至 108 mm，且 PWM 升高，因此回退 |
| r2 | 16,384 步。以原检查点重跑，降学习率至 2e-5，增强位移代价。强扰动位移 P95 由 146 mm 降至约 138 mm |
| r3 | 24,576 步。从第 5 个检查点起步并惩罚接近 PWM 限幅。漂移缩小，PWM 跳变明显升高 |
| 权重平均 | 同一训练轨迹的第 3 与第 5 个检查点按 40% / 60% 混合。标准推扰位移 P95 为 73 mm，PWM 幅值 RMS 为 168 |
| r4 | 12,288 步。从权重平均模型小步续训，额外惩罚 PWM。未改善综合指标，保留权重平均模型 |

这四轮 PPO 共 86,016 步。独立 30 秒强扰动组完成率由 31/32 升至 32/32。独立 60 秒强扰动组两者均为 16/16，峰值位移 P95 从 137 降到 95 mm，PWM 幅值 RMS 从 317 降到 261，PWM 跳变 RMS 则从 80 升到 94。两组的种子与后续平滑任务不同，跨组数值不直接比较。该轮选型和复测全部保存在 [抗扰评估](../results/first-order/robust/evaluation.json)。

## 一阶平滑续训

1. 从上一轮权重平均检查点继续两轮 PPO，共 57,344 步。第一轮提高 PWM 跳变代价，24 秒强扰动组跳变 RMS 从 94.6 降到 90.2，位移 P95 从 144 升到 152 mm。第二轮提高位移代价，跳变略降，位移没有恢复到基线。
2. 采集 50,400 个教师状态，训练两档平滑蒸馏候选。平稳状态在训练期间使用轻度平滑目标，较大倾角和高角速度时保留快速纠偏目标。执行时继续只读当前观测，直接输出 PWM。
3. 以未用于训练的数据种子复测，选中强平滑档。用 2,000 组输入比对同一策略的 C 与 Python 前向结果，最大动作差 2.980e-7。硬件回路和传感器校准仍待验证。

## 二阶带摆杆训练

### 模型与接口

现有 MuJoCo 模型包含约 0.9 kg 车身、0.39 m 摆杆、两轮和一个被动摆杆铰链。车身和摆杆角分别相对竖直定义。摆杆绝对角等于车身角加相对铰链角。摆杆绝对角速度同理。模型使用固定 8 维观测缩放，不需要一阶的归一化文件。

| 序号 | 量 | 预处理除数 |
| --- | --- | ---: |
| 1 | 车身俯仰 rad | 0.05 |
| 2 | 车身俯仰角速度 rad/s | 0.8 |
| 3–4 | 左右轮相对车身角速度 rad/s | 4 |
| 5 | 轮速估算的里程 m | 0.16 |
| 6 | 估算前向速度 m/s | 0.20 |
| 7 | 摆杆绝对俯仰 rad | 0.05 |
| 8 | 摆杆绝对俯仰角速度 rad/s | 0.8 |

两个归一化动作各乘 4500，再按场景 PWM 上限截断。仿真保护阈值为车身 0.14 rad、摆杆 0.19 rad、轮速 18 rad/s。最终评估位移上限 0.20 m。较难组随机加入 0 或 10 ms 执行延迟、摩擦、陀螺角度偏置和左右驱动增益差。真车上的比例、符号、摆杆铰链和电机动态需要单独测量。

### 收敛过程和调整

- **小倾角课程。** 零 PWM 对照通常在约 0.25 秒触发车身倾角保护。随机初始化 PPO 依次取得约 0.53、0.70、0.94、5.43 秒平均时长。首个完整通过的检查点在 307,200 步达到 12/12 个 8 秒回合，368,640 步保持该结果并进一步降低位移。
- **难度跃迁。** 同时扩大初始角度、加入驱动差异、延迟和推扰后，12 秒混合组只有 0/16 局撑满，续训到第三个检查点后平均为 3.37 秒。拆分因素后，在 8 秒、0.12 N 的仅推扰组，原策略只有 1/12 局完成，推扰成为优先解决的问题。
- **恢复课程。** 部分训练环境保留无推扰样本，另一部分提前施加小推扰，增加遭遇扰动后的恢复样本。这一分支在 12 秒、0.08 N 的 12 局检查中完成 9 局。随后增加推扰幅度和位移代价，比较检查点而不按步数自动替换候选。
- **按回报搜索。** 使用闭环仿真回合得分搜索神经网络输出层参数，保持两个动作都来自同一策略网络。三轮搜索扩大种子集合和每组样本数，再拉长回合。各 PPO 分支合计 1,290,240 步。三次回报搜索共评估 4,488 个候选回合，另有独立复测。
- **最终选型。** 把第二轮搜索第 11 个检查点和长回合搜索第 9 个检查点的输出层按 65% / 35% 合并。长回合检查点单独使用时，60 秒静止组的 PWM 幅值 RMS 约 501 且车身角 RMS 约 1.02°。混合候选保留了轻扰动完成率，同时把自身独立 60 秒静止组的 PWM 幅值 RMS 控制在约 152、车身角 RMS 约 0.105°。

| 复测 | 完成局数 | 车身 / 摆杆角 RMS | 位移 P95 | PWM 限幅 | 初始角 / 推扰 |
| --- | ---: | ---: | ---: | ---: | --- |
| 60 秒无推扰 | 20/20 | 0.105° / 0.051° | 30 mm | ±2500 | ±0.57° / 0 N |
| 30 秒轻推扰 | 32/32 | 1.365° / 0.628° | 178 mm | ±4500 | ±0.57° / 0.08 N |
| 20 秒较难工况 | 9/24 | 1.386° / 0.611° | 172 mm | ±4500 | ±1.38° / 0.12 N |

两个长时组使用独立种子 172781。较难组在种子 122603 上用于比较检查点，15 局触发车身倾角保护，平均完成 11.19 秒。由此保留“轻扰动站立”结论，较大初始偏差和延迟下的恢复仍是短板。见 [二阶评估](../results/second-order/balance/evaluation.json)。
